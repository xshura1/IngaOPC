Описание доступных классов.

 

Ниже дано описание классов, которые доступны в скриптах шаблонов. Свойства, выделенные таким образом так же доступны в инспекторе объектов.

 

TIGVQT

класс предназначен для передачи значений тэгов от клиента к серверу при выполнении записи значений.

 

TIGProp

класс предназначен для работы с дополнительными свойствами тэга.

 

TIGTag

класс предназначен для работы с тэгами.

 

TIGTags

класс содержит массив тэгов.

 

TIGCommand

класс предназначен для формирования пакета данных и отправки этого пакета в драйвер.

 

TIGDriverData

класс содержит пакет данных, полученный из драйвера.

 

TIGDevice

класс содержит данные устройства.

 

TIGVQT

Класс предназначен для передачи значений тэгов от клиента к серверу при выполнении записи значений.

property Value:OleVariant

(только чтение)

свойство содержит значение тэга для записи в устройство

property ValueAsArray[index]:OleVariant

(только чтение)

если тип данных тэга – массив (проверяется вызовом функции ValueIsArray), то свойство содержит массив значений

function ValueIsArray:Boolean

(только чтение)

будет истинно если тип данных тэга - массив

 

 

TIGProp

Класс предназначен для работы с дополнительными свойствами тэга

property UniqueValue:boolean;

(только чтение)

если данное свойство привязано к нескольким тэгам, то проверяется уникальность значения свойства у каждого тэга

property DataType:word

(только чтение)

указывает тип данных свойства

property ID:dword

идентификатор свойства (подробнее см. документацию OPC DA)

property Value:OleVariant

(только чтение)

содержит значение свойства, если тип данных не массив

property ValueAsArray[index]:OleVariant

(только чтение)

содержит значение свойства, если тип данных массив

function ValueIsArray:Boolean

(только чтение)

будет истинно если тип данных свойства – массив

 

 

TIGTag

Класс предназначен для работы с тэгами

Свойства доступные для редактирования в редакторе шаблонов

property Name:string;

(только чтение)

содержит имя тэга, которое впоследствии будет видно в адресном пространстве сервера

property DataType:word;

(только чтение)

тип данных тэга

property IsReadable:boolean;

(только чтение)

указывает, что тэг доступен для чтения клиентами

property IdWriteable:boolean;

(только чтение)

указывает, что тэг доступен для записи клиентами

property IsStored:boolean;

(только чтение)

при истине, значение, качество и метка времени, сохраняются в файл

property OldValue:OleVariant;

property OldValueAsArray[index:integer]:OleVariant;

(только чтение)

содержит значение тэга, которое доступно в данный момент клиентам

property OldValueAsArrayCount:integer;

property NewValueAsArrayCount:integer;

(только чтение)

если тип значения – массив, то свойство показывает кол-во ячеек массива

property NewValue:OleVariant;

property NewValueAsArray[index:integer]:OleVariant;

(чтение и запись)

содержит значение тэга, которое будет доступно клиентам после выполнения скрипта

property OldQuality:word;

(только чтение)

содержит качество тэга, доступное клиентам

property NewQuality:word;

(чтение и запись)

содержит качество тэга, которое будет доступно клиентам после выполнения скрипта

property ValueIsArray:boolean;

(только чтение)

указывает, что тип данных тэга - массив

property Prop[index:dword]:TIGProp;

(только чтение)

массив дополнительных свойств тэга, конкретное свойство доступно по его индексу (ID)

property CountProps:integer;

(только чтение)

кол-во дополнительных свойств тэга

function PropExists(ID:dword):boolean;

(только чтение)

указывает наличие дополнительного свойства тэга по ID свойства

property VQT:TIGVQT;

(только чтение)

при записи в тэг, содержит значение для записи

События для TIGTag

procedure OnRead(Device:TIGDevice;

Tags:TIGTags);

событие вызывается в следующих случаях:

- при добавлении тэга в группу;

- при изменении активности тэга;

- при чтении тэга.

procedure OnWrite(Device:TIGDevice;

Tags:TIGTags);

событие вызывается при записи в тэг

 

 

TIGTags

Класс содержит массив тэгов

property Tag[index:integer]:TIGTag;

(только чтение)

массив тэгов

property Count:integer;

(только чтение)

указывает кол-во тэгов в массиве

property Filter:string;

(чтение и запись)

свойство содержит строку скрипта, для фильтрации тэгов в массиве

property Filtered:boolean;

(чтение и запись)

указывает, наложен ли фильтр на массив тэгов на основе строки Filter

property SortScript:string;

(чтение и запись)

содержит скрипт для задания порядка сортировки тэгов в массиве

property Sorted:boolean;

(чтение и запись)

указывает отсортирован ли массив тэгов на основе скрипта в SortScrtipt

 

 

TIGCommand

Класс предназначен для формирования пакета данных и отправки этого пакета в драйвер

property Count:integer;

(чтение и запись)

возвращает кол-во байт в массиве Data, при записи изменяет длину массива

property Priority:word;

(чтение и запись)

приоритет команды (если необходимо подать команду как можно быстрее, то необходимо изменить приоритет в меньшую сторону), по умолчанию все команды имеют приоритет 1000

property Data[index:integer]:byte;

(чтение и запись)

массив байт, который будет передан в драйвер

procedure Run;

процедура добавляет команду в очередь для отправки в драйвер

События для TIGCommand

procedure OnBeforeWrite(Device:TIGDevice;

Command:TIGCommand;

var Cancel:boolean);

событие возникает при подаче команды в драйвер

procedure OnAfterRead(Device:TIGDevice;

Command:TIGCommand;

DriverData:TIGDriverData);

событие возникает после приема ответа от драйвера

 

 

TIGDriverData

Класс содержит пакет данных, полученный из драйвера

property Data[index:integer]:byte;

(только чтение)

массив байт, полученный из драйвера

property Count:integer;

(только чтение)

кол-во байт в массиве Data

property Result:dword;

содержит результат выполнения драйвером команды (формируется драйвером)

 

 

TIGDevice

Класс содержит данные устройства

property Tags:TIGTags;

(только чтение)

содержит массив тэгов, принадлежащих данному устройству

property Address:string;

(чтение и запись)

адрес устройства

property Param:dword;

(чтение и запись)

дополнительный параметр устройства
