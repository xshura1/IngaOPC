Драйвер устройства.

Драйвер представляет собой динамически подключаемую библиотеку (DLL), написанную на каком- либо языке высокого уровня. В драйвере реализуются следующие функции:

 

function Write(ppDriverData : pDriverData):HResult; stdcall;

 

Назначение: 

данная функция служит для принятия пакета данных от сервера и для формирования физического пакета, который затем будет отправлен на устройство по какому- либо каналу связи (COM, LPT, TCP/IP и т.д.).

 

Когда вызывается:

функция вызывается сервером всякий раз, когда необходимо отослать данные на устройство.

 

Возвращаемое значение:

HResult = s_ok – драйвер принял пакет данных и сервер ожидает ответа на пакет посредством функции Read (см. ниже);

HResult = s_false – в данный момент драйвер не может принять пакет данных, сервер пошлет этот пакет позже;

 

 

 

function Read(out ppDriverData : pDriverData):HResult; stdcall;

 

Назначение: 

функция служит для принятия сервером данных от устройства.

 

Когда вызывается:

вызывается постоянно.

 

Возвращаемое значение:

HResult = s_ok – у драйвера есть данные для сервера;

HResult = s_false – у драйвера нет данных для сервера;

 

 

function OpenDriver:HResult; stdcall;

 

Назначение: 

в этой функции обычно реализовывается инициализация драйвера (открытие канала связи, считывание различных параметров, необходимых для работы драйвера).

 

Когда вызывается:

функция вызывается при подключении хотя бы одного клиента к серверу.

 

Возвращаемое значение:

HResult = s_ok

 

 

function CloseDriver:HResult; stdcall;

 

 Назначение: 

в этой функции должен быть реализован код для закрытия каналов связи.

 

Когда вызывается:

функция будет вызвана сервером, когда будет отключен последний клиент.

 

Возвращаемое значение:

HResult = s_ok

 

 

function ShowDialog:HResult; stdcall;

 

Назначение:

в этой функции может быть реализован код показа окна настроек драйвера.

 

Когда вызывается:

функция будет вызвана сервером, когда пользователь выберет драйвер из списка драйверов в меню "Настройки драйверов".

 

Возвращаемое значение:

HResult = s_ok

 

 

 

В функциях Write и Read используется следующая структура:

 

pDriverData = ^DriverData;

DriverData = record

   Handle                         :dword;

   szAddress                    :POleStr;

   szNoCommand            :POleStr;

   Param                          :dword;

   dwDataSize                 :dword;

   pData                           :PByteArray;

   Result                          :dword;

end;

 

Описание полей структуры:

 

Handle

Уникальный идентификатор пакета, который необходим серверу для приведения соответствия между переданным пакетом в функции Write и принятым пакетом в функции Read. Пример: драйвер принял пакет от сервера, сформировал на его основе физический пакет, отослал пакет на устройство, затем принял ответ. Этот ответ, драйвер упаковывает в структуру DriverData, Handle этого пакета должен быть таким же как и у переданного сервером. В подготовленном пакете для отправки в сервер (функция Read) этот идентификатор может принять значение равное 0, в этом случае сервер будет искать соответствие по строкам адреса и номеру команды (см. ниже).

szAddress

Строковое значение адреса устройства. На его основе, драйвер должен сформировать данные об адресе, понятные устройству. Адрес устройства задается в редакторе конфигурации. В возвращаемой структуре (функция Read) допускается оставлять это поле пустым (nil), если идентификатор пакета (Handle) не равен 0.

szNoCommand

Строковое значение номера команды. На его основе, драйвер формирует номер команды для устройства, или же какие либо другие действия. В возвращаемой структуре (функция Read) допускается оставлять это поле пустым (nil), если идентификатор пакета (Handle) не равен 0.

Param

Дополнительный, пользовательский параметр, который передается без изменения в драйвер и который может быть любым при формировании ответа в функции Read.

dwDataSize

Указывает кол-во байт данных в массиве pData.

pData

Массив байтов длиной dwDataSize в котором содержатся данные для отправки данных в устройство (функция Write) и для отправки принятых данных от устройства в функции Read.

Result

В этом поле содержится результат выполнения команды драйвером, может иметь любое значение, которое будет использовано при обработке данных в скриптах шаблона. В случае отправки данных в драйвер (функция Write) это поле не используется.

 

Распределение памяти для структуры DriverData.

В случае отправки данных сервером драйверу (функция Write), память под структуру распределяется сервером.

В случае передачи данных серверу (функция Read), память под структуру должна выделяться драйвером а освобождаться сервером. Пример распределения памяти:

var pdd:pDriverData;

 

pdd:=coTaskMemAlloc(sizeof(DriverData));

pdd^.szAddress:=StringToLPOleStr('Address');

pdd^.szNoCommand:=StringToLPOleStr('No');

pdd^.dwDataSize:=20; // пример!

pdd^.pData:=coTaskMemAlloc(pdd^.dwDataSize);
